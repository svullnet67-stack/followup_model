所有分析结果均需人工复核。未提及 ≠ 已解决，已回应 ≠ 已接受。本地规则分析 · 请定期备份项目文件

开始一次有据可循的复盘

  1. 添加历次沟通

    填写学生代号，每次沟通填写日期与内容。角色标签可以提高识别准确性。

  2. 对比全部记录

    系统按日期排序，比较最新沟通与历史信息，跟踪顾虑和明确行动陈述。

  3. 核对原话

    点击“查看原话依据”展开证据，再点日期可以定位到相应记录。结果可以人工编辑。

  4. 保存与分享报告

    “保存本机缓存”存入当前浏览器的本地存储。移动程序文件、切换浏览器或清理缓存后可能无法找到项目。“备份项目文件”生成可备份的 JSON 文件，也可导入桌面版的项目 JSON；导入后重新分析。TXT 报告可用于沟通准备。

当前版本的能力

无需安装 Python，无需登录或联网。桌面启动器使用已安装的 Edge 或 Chrome 打开独立窗口，核心是本地 HTML 应用。采用规则分析，尚未训练专用模型。暂未连接模型 API，不提供跨设备自动同步。清除浏览器数据会删除本机项目，请下载备份。

“表述变化”不必然代表事实改变，复杂指代和多个同类约定仍需人工核对。请使用获授权、已脱敏的记录。

编辑完整报告

修改影响复制和 TXT 导出，不改变原始分析卡片。重新分析将替换编辑结果。
