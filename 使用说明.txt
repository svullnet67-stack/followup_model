跟进助手：网页与训练模型服务部署包

本包包含已收到的最新模型配置（270条训练、30条验证、5轮）及分词器，不含 model.safetensors。
1. 解压本包。
2. 从最新训练对应的 best 文件夹复制 model.safetensors 到本包 model 文件夹，和 config.json 放在一起。不要混入旧版本权重。
3. 在本包目录打开 PyCharm 终端，逐条执行：
python -m pip install -r requirements.txt
python server.py
4. 浏览器访问 http://127.0.0.1:8080/model.html 测试真实模型。
首页 http://127.0.0.1:8080/ 保留本地桌面版已有规则复盘功能，可点击“进入训练模型”跳转。

功能边界
原复盘页面仍为规则分析；新增模型页面明确调用真实权重。当前不是整段录音自动提取所有行动再逐项模型判断的完全整合版。目标事项和相关片段由使用者输入。模型缺失或不可用时不提供伪造结果。
浏览器原有项目保存在各自网址的本地存储中，更换域名不会自动迁移，先在旧页面下载备份再在新页面导入。新模型页面不自动保存输入。

云端部署
本包必须部署到支持 Docker/Python 的后端服务，不能上传到“静态网站托管”作为完整应用运行。
建议下一步打开 CloudBase 左侧“云函数/托管”，确认容器托管入口、可用资源和费用，再上传含权重的完整包。
Dockerfile 使用 Python 3.11，服务端口8080，健康检查路径 /health。网页与API由同一服务提供，不需要另外设置跨域。
容器在根路径 / 提供服务，请勿把这份完整应用按静态项目部署到 /followup-review。
本地默认只监听127.0.0.1，容器设置 HOST=0.0.0.0。模型启动时从本地加载，不下载远程权重。
构建镜像需要网络安装Python依赖；如云平台无法访问安装源或基础镜像仓库，需要按该平台提供的镜像源配置。
内存与响应时间尚未实测；先完成本机测试后，根据平台资源规格选择，勿仅凭权重文件大小选择内存。
公开演示前通过平台设置HTTPS、请求速率/并发限制及费用告警。接口每次只执行一个推理，繁忙返回429。本程序不主动保存或打印对话，云平台日志策略仍需核查。

已验证：配置标签顺序、训练输入拼接格式、Python及JavaScript语法、ZIP目录结构。
未验证：实际权重加载、模型预测、云端构建、腾讯云发布和国内网络访问（权重未成功载入本工作区）。
